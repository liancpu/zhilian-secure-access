## 使用约定

- 示例主要面向 Linux；明确标注的 curl 命令也可在具备相应功能的 macOS 使用。Windows 请调用 `curl.exe` 并按终端调整换行。
- `example.com`、`<目标IP>` 等是占位符。测速应使用自有或获准的测试端点，不对第三方站点进行持续压测。
- 一次只调整一个变量，先保存原配置，再测量并验证；生产网络变更应具备恢复入口。
- 不向公开 Issue 上传订阅地址、账号密码、令牌、订单信息或未脱敏日志。
- 文档依据 2026-10-09 核查的上游资料编写。版本相关选项以本机帮助和对应版本文档为准。
